# Meghasri K R — Portfolio

## Run locally
1. Keep `index.html`, `style.css`, `script.js` and `Meghasri_KR_Resume.pdf` in the same folder.
2. Open `index.html` in a browser.

## Customize
- Replace the resume PDF with the latest file using the same filename.
- Add GitHub when you have a profile by adding another button/link in the contact section.
- Skill percentage bars are visual only; they are not formal proficiency scores.

## Deploy
This static site can be deployed on GitHub Pages, Netlify, or Vercel.
